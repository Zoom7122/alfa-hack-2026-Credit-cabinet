# Credit Engine

Компонент учебного кредитного кабинета для оценки заявок индивидуальных предпринимателей и юридических лиц. Состоит из двух HTTP-сервисов на Go и Gin:

| Сервис | Назначение | Адрес по умолчанию |
|---|---|---|
| `scoring-service` (МС1) | Оценка заёмщика и подбор условий кредита | `:8082` |
| `bank-state-service` (МС2) | Проверка сделки на состоянии банка и учёт учебной выдачи | `:8083` |

В текущей версии доступны запуск сервисов, проверка конфигурации и `GET /healthz`. Обработка кредитных заявок, расчёт предложений и выдача через API пока недоступны.

## Запуск

Требуется Go 1.26.8 или новее. Все команды выполняются из каталога `credit-engine/`.

В первом PowerShell-терминале запустите сервис оценки:

```powershell
$env:STATEMENTS_URL = 'http://statements:8080'
go run ./cmd/scoring-service
```

Во втором терминале запустите сервис состояния банка:

```powershell
$env:ADMIN_URL = 'http://admin:8080'
go run ./cmd/bank-state-service
```

`STATEMENTS_URL` — базовый URL поставщика бухгалтерской отчётности, `ADMIN_URL` — базовый URL сервиса административных уведомлений. Замените адреса из примеров адресами своих сервисов. Эти внешние компоненты в поставку Credit Engine не входят; их доступность при запуске не проверяется.

Проверка работоспособности:

```powershell
Invoke-RestMethod http://localhost:8082/healthz
Invoke-RestMethod http://localhost:8083/healthz
```

Оба сервиса возвращают HTTP 200 с телом:

```json
{"status":"ok"}
```

Для остановки используйте `Ctrl+C`.

## Настройки

| Переменная | Сервис | Значение по умолчанию / назначение |
|---|---|---|
| `SCORING_ADDR` | МС1 | `:8082` |
| `BANK_ADDR` | МС2 | `:8083` |
| `BANK_URL` | МС1 | `http://localhost:8083` |
| `STATEMENTS_URL` | МС1 | Обязательный базовый HTTP(S) URL поставщика отчётности |
| `ADMIN_URL` | МС2 | Обязательный базовый HTTP(S) URL административного сервиса |
| `POLICY_FILE` | Оба | `config/policy.json` |
| `BANK_STATE_FILE` | МС2 | `config/bank.default.json` |
| `DEMO_EVALUATION_DATE` | МС1 | Фиксированная дата оценки в формате `YYYY-MM-DD`; по умолчанию текущая дата UTC |
| `BANK_TIMEOUT` | МС1 | `4s` |
| `STATEMENTS_TIMEOUT` | МС1 | `2s` |
| `ADMIN_TIMEOUT` | МС2 | `2s` |
| `HTTP_WRITE_TIMEOUT` | Оба | `15s` |

Относительные пути к файлам конфигурации разрешаются от текущего рабочего каталога. Политика и начальное состояние банка проверяются до открытия HTTP-порта; некорректная конфигурация завершает запуск с ошибкой.

Базовые URL могут содержать префикс пути, но не учётные данные, параметры запроса или fragment. Тайм-ауты задаются положительными длительностями, например `2s`. `HTTP_WRITE_TIMEOUT` МС1 должен превышать сумму `STATEMENTS_TIMEOUT` и `BANK_TIMEOUT`, а МС2 — `ADMIN_TIMEOUT`. При изменении настроек оставляйте вызову МС1 → МС2 время на обращение МС2 к административному сервису.

## API

Схемы запросов и ответов описаны в [OpenAPI](contracts/openapi.json), Go-типы — в [contracts/contract.go](contracts/contract.go). Кредитные маршруты в контракте описывают целевой API; сейчас реализован только `/healthz`.

Кредитные ставки `max_annual_rate` и `annual_rate` передаются в процентах: `1` означает 1%, `23.75` — 23,75%, `100` — 100%. Допустимый диапазон — от 0 до 100 включительно, точность — до двух знаков после точки. Пример выбранных условий по контракту:

```json
{
  "amount_rub": 3000000,
  "term_months": 24,
  "annual_rate": 23.75
}
```

Денежные суммы запроса задаются целыми рублями, сроки — целым числом месяцев. Нормативы и экономические коэффициенты сохраняют формат долей единицы: `0.30` означает 30%.
