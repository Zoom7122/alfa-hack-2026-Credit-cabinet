# REST-клиент поставщика фактов

[FactsClient](../internal/clients/facts.go) выполняет один POST /api/v1/scoring-facts за всем именованным блоком выбранной модели. Он получает запись каталога, исходный ScoringFactsRequest и явную дату оценки; версию не выбирает и не заменяет. Автоматические повторные запросы и кэш ответов отсутствуют.

## Настройки МС1

| Переменная | Значение |
|---|---|
| FACTS_URL | Необязательный HTTP(S) base URL поставщика; для каталога без SUPPLIER не требуется. |
| FACTS_TIMEOUT | Положительная Go duration, по умолчанию 2s. |
| HTTP_WRITE_TIMEOUT | При настроенном поставщике строго больше FACTS_TIMEOUT + STATEMENTS_TIMEOUT + BANK_TIMEOUT; по умолчанию 15s. |

Если URL не настроен, прежний бюджет STATEMENTS_TIMEOUT + BANK_TIMEOUT сохраняется. Наличие моделей, которым нужен поставщик, дополнительно проверяется при сборке приложения: такая модель не должна работать без зависимости. Входные URL не содержат credentials/query/fragment, ошибки настройки не выводят их содержимое.

## Вызов

Fetch получает исходный контекст операции. Тайм-аут HTTP-клиента и дедлайн вызывающей стороны действуют на запрос/чтение. Тело строится только из четырёх полей протокола с вложенным borrower; INN=null передаётся явно. Даты/случайные ID для изменения идентичного повторного запроса не добавляются.

Модель без SUPPLIER возвращает пустой дополнительный контекст без HTTP-вызова и без требования создать клиент. Для модели с поставщиком проверяются соответствие запроса выбранной записи каталога и ненулевая дата; затем отправляется один запрос.

Ответ ограничен 1 MiB и глубиной 64, проверяется один JSON-документ, UTF-8 и дубли ключей. После этого запись каталога вызывает декодер точного сгенерированного DTO с ожидаемыми ID/версиями/датой. Nullable-значения и типизированный доступ сохраняются; raw-map не заменяет DTO. Тело ответа закрывается при успехе и ошибке.

## Ошибки

| Ситуация | HTTP МС1 / код |
|---|---|
| Соединение/чтение недоступно, неожиданный статус, редирект, включая 404 поставщика | 502 FACTS_UNAVAILABLE |
| Тайм-аут клиента/входного дедлайна/чтения | 504 DEPENDENCY_TIMEOUT |
| Некорректный JSON/оболочка/типы/домен/дата/лимит тела | 502 INVALID_FACTS_RESPONSE |
| Чужие ID/тип заёмщика | 502 FACTS_ID_MISMATCH |
| Другая модель/схема | 502 FACTS_VERSION_MISMATCH |

Отмена контекста прекращает запрос без повторов; причина сохраняется для errors.Is/As. Ошибка не печатает URL/ответ/секреты. Клиент не обращается к банку и не превращает техническую ошибку в бизнес-маршрут. Неизвестный обязательный факт, корректно переданный null, проверяется общим скорингом после подтверждённых стопов.

Контракт и правила повторов приведены в [спецификации поставщика](09_scoring_facts_contract.md). Подключение клиента к выбору модели и постоянному HTTP-конвейеру МС1 выполняется на этапе сборки этого конвейера.
