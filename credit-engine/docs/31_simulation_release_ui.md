# Проверка и выпуск через интерфейс

Откройте «Проверка и выпуск» или ссылку проверки сохранённой ревизии черновика. Сначала сохраните локальные изменения: расчёты используют только опубликованную версию либо точную неизменяемую ревизию.

## Расчёт и сравнение

Выберите модель справа и, для сравнения, модель слева. Вставьте или загрузите JSON набора по формату simulation. Полные примеры находятся в testdata/simulation/ip-v2.json и le-v2.json. Дата оценки задаётся явно, данные поставщиков вводятся самостоятельно. Набор не сохраняется сервером.

«Выполнить расчёт» показывает маршрут, класс/итог при наличии, причины, недостающие поля, значения/ответы/баллы критериев и их включение в итог. Раскрываемые разделы показывают исходные/эффективные параметры, проверки, условия и применение правил. Неизвестное значение обозначено явно; boolean false и числовой ноль сохраняются.

«Сравнить расчёты» использует один набор для обеих моделей, показывает изменения критериев, итогов и два результата. «Показать изменения модели» работает без набора: контрольные суммы, JSON Pointer изменённых полей, исходное и новое определения.

## Предпросмотр и подготовка

Укажите новую версию релиза, базовый подготовленный релиз, описание и полный состав опубликованных версий/ревизий. Включите необходимые прежние версии для совместимости. Выбор ревизий закреплён на момент открытия страницы; при изменении черновика сервер потребует обновления.

«Проверить и показать документы» вызывает POST /api/admin/v1/releases/preview с тем же release, что последующая подготовка. Маршрут защищён сессией/Origin/CSRF. Генерируется тот же воспроизводимый комплект без записи в БД, файловых изменений или активации МС1. Возвращаются manifest/manifest_sha256 и текстовые documents(path/content): OpenAPI МС1/поставщика, Markdown таблиц и описание изменений. Тексты отображаются безопасно, без выполнения HTML.

Ошибка общей валидации, включая недобор/превышение 750/250/1000, показывает конкретные пути и блокирует подготовку. После успешного предпросмотра и указания основания доступна подготовка. Изменение состава требует повторного предпросмотра; сервер повторно проверяет всё при фиксации.

Готовый ZIP скачивается с SHA-256. Подготовленный комплект ещё не является работающей сборкой. Для применения следуйте процедуре генерации, сборки, тестирования и согласованного развёртывания.
