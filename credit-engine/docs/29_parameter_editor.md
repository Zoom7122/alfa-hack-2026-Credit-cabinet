# Редактор параметров и баллов

Редактируется только текущая ревизия черновика. Опубликованная модель и исторические ревизии доступны для чтения. «Применить к черновику» меняет локальное определение; «Сохранить новую ревизию» отправляет его на сервер с основанием и ожидаемой ревизией. При конфликте локальные изменения можно скачать, затем сопоставить с актуальной ревизией. Несохранённые изменения вызывают предупреждение при уходе.

## Параметры

Новый параметр относится к SUPPLIER: число или boolean, JSON-имя, необязательное имя Go-поля, единица, целочисленность и открытые/закрытые границы числового домена. Его можно использовать в любом балльном блоке. Версия схемы поставщика задаётся явно. Новые поля не добавляются в запрос А.

Для существующих источников APPLICATION/STATEMENTS/COMPUTED сохраняется доверенная привязка и тип. Можно изменить название, описание, обязательность, условие обязательности, зависимости и активность. ID сохранённого объекта постоянный; другое имя создаётся новым объектом. Перед отключением/удалением показаны связанные параметры, критерии, проверки, стопы и основания рассмотрения. Каскадное удаление не выполняется, сервер дополнительно проверяет доверенные зависимости расчётов.

## Критерии

Доступны блоки QUESTIONNAIRE/ADDITIONAL, максимум, параметр результата, поведение при неизвестности, условие применения, обычные/особые случаи. У каждого варианта задаются условие и баллы, при необходимости специальный результат или основание рассмотрения. Текстовые ответы и условные тексты существующей анкеты сохраняются и редактируются.

Условия задаются деревом: И/ИЛИ/НЕ, сравнения, принадлежность списку, известность/неизвестность. Литералы типизированы; null не является литералом сравнения. Открытость диапазонов задаётся операторами <, ≤, >, ≥. Числа передаются точными JSON-токенами, включая int64 выше 2^53.

Максимумы и отклонения от 750/250/1000 отображаются при изменении критерия и в черновике. Сохранение промежуточного неверного распределения допустимо; выпуск требует общей серверной проверки. Клиентский подсчёт максимумов не заменяет проверку покрытия шкал, ссылок, типов и зависимостей.
